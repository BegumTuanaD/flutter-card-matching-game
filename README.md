# 🃏 Card Matching Game

A memory card matching game developed using **Flutter and Dart**.

## 📱 About the Project

Card Matching Game is a mobile game designed to improve memory and concentration by matching identical cards.

## ✨ Features

- 12, 16 and 20 card options.
- Interactive card grid.
- Emoji-based memory cards.
- Score tracking system.
- Matched cards become disabled.
- Mismatched cards are hidden after a short delay.

## 🛠️ Technologies Used

- Flutter
- Dart
- Android Studio

## 🎮 How to Play

1. Select the number of cards.
2. Tap on two cards to reveal them.
3. Try to find matching pairs.
4. Match all pairs to complete the game.
